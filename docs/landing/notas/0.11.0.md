## Description (Markdown)

````markdown
### New: "Web" module - URL and domain inspection kit

A complete toolkit to analyze URLs and domains without leaving the app:

- **URL inspection**: homoglyphs (characters from other alphabets that mimic Latin letters), punycode and typosquatting (detection of impersonated brands, e.g. "gogle" vs "google").
- **TLS**: issuer, subject, validity, SANs and certificate expiry alert.
- **HTTP headers**: HSTS, CSP, X-Frame-Options, X-Content-Type-Options, cookies and status code.
- **DNS**: A/AAAA/MX/TXT/CNAME/NS records.
- **Email**: format validation + MX + SPF/DMARC/DKIM.
- **Utilities**: tracking parameter cleaner (utm_*, fbclid, ...), two-URL comparison and short-link expansion (redirect chain).

### New: "AI" module - Markdown conversion and Ollama

- **markItDown**: detects Python and markItDown, installs the package via pip if missing, and converts files (PDF, DOCX, XLSX, PPTX, images, audio, HTML...) to Markdown. The `.md` is generated next to the original file.
- **Ollama**: detects the installation and lists local models (name, size, date).

### ClamAV: real cancellation of elevated scans

Cancelling a scan now kills the elevated ClamAV process for real (previously only the wait was stopped and the console could stay open). Graceful degradation if the user declines the UAC prompt.

### Local Share: temporary web client

Time-limited HTTP link protected by a cryptographic token, so any browser (without PCSuite installed) can download the shared files. Read-only, anti-traversal, auto-shutdown.

### Security Center: opt-in Geo IP

"Geo IP" toggle (off by default for privacy) that looks up the country of remote IPs in TCP connections. Clear notice that IPs are sent to an external service.

### Dev Tools: npkill fix

The "Select folder and run npkill" button now keeps the console open and shows errors instead of closing silently.

### Documentation and quality

- Vitest configured for the frontend (tests for the AI and Web pages).
- xUnit: 24 tests for the AI module and 9 for the Web module.
- Cross-platform roadmap (Mac/Linux/Android) recorded in the plan.

#### Compatibility note

All protocol changes are additive: a PCSuite 0.10.x receiving transfers or messages from a 0.11.0 processes them exactly as before.
````
