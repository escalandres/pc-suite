## Description (Markdown para el release)

````markdown
The Swiss Army Knife for Windows developers and power users.

Primera versión pública de **PCSuite**, en fase de desarrollo activo (versiones 0.x): una suite de escritorio para Windows 10/11 con antivirus, gestor de software, WSL, SSH, PGP, limpieza, seguridad y **Local Share** — envía archivos entre tus equipos por la red local, sin nube y con cifrado TLS de extremo a extremo.

> ℹ️ **Sobre el número de versión**: los builds internos previos (1.x) nunca se publicaron; la numeración pública arranca en 0.5.0 para reflejar honestamente la fase de desarrollo.

## ✨ Lo destacado

- **Local Share** — Transfiere archivos entre PCs con PCSuite: se detectan solos en la red, se emparejan con un código de comparación de 6 dígitos (estilo Bluetooth) y todo viaja cifrado con verificación SHA-256. Incluye reanudación de transferencias interrumpidas, pausa, cancelación y límite de ancho de banda.
- **Todo en proceso** — PGP con BouncyCastle, SSH, WSL y limpieza: nada de servidores externos, nada de telemetría.
- **Instalador inteligente** — Detecta una versión anterior y la reemplaza limpiamente; tu configuración, dispositivos emparejados e historial no se tocan.
- **Elevación puntual** — La app nunca corre como administrador: cada operación privilegiada pide UAC individual (y solo cuando toca).

## 🧩 Módulos

**Local Share** · **Antivirus** (ClamAV: escaneo rápido/completo, cuarentena) · **Software** (WinGet: buscar, instalar, actualizar) · **WSL** · **SSH** (claves: generar, inspeccionar, importar) · **PGP** (cifrar, firmar, verificar) · **Limpieza** · **Seguridad** (Defender, firewall, puertos) · **Plugins** · **Tools**

## 💻 Requisitos

- Windows 10/11 (x64)
- WebView2 Runtime (preinstalado con Edge)
- Sin .NET necesario: la app es autocontenida

## 🔒 Privacidad

PCSuite no envía nada a ningún servidor. Las transferencias de Local Share van directo entre tus equipos por tu red local.

## 🔄 Actualizar desde un build interno (1.x)

Los builds 1.x previos fueron internos. Para pasar a la 0.5.0, simplemente descarga e instala encima: el instalador detecta y reemplaza la versión anterior sin tocar tu configuración.
