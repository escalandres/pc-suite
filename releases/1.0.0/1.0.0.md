## Description (Markdown)

````markdown
### PCSuite 1.0.0 - First stable release

PCSuite is the Swiss Army Knife for Windows developers and power users: a single
desktop app that bundles the everyday tools you reach for - encoding, hashing,
password generation, package management, WSL, antivirus, SSH/PGP, file security,
local file sharing, URL/domain inspection, AI helpers and system repair - all
behind a typed, secure bridge between a React UI and a .NET host.

This is the first stable release. Every feature listed below has been built,
tested and shipped incrementally (0.5.0 → 1.0.0).

### Tools and utilities

- **Tool framework**: JSON formatter, UUID generator, Base64, Hash, Password generator.
- **Developer providers**: Node, npm, pnpm, Bun, Claude Code - detection, version, update and launch.
- **Certificates / Cipher**: Base64, Hex, URL, ROT13, Caesar, Binary, Morse; instant hashing; AES-256-GCM and XOR.
- **Files**: AES-256 password protection (files and whole folders), SHA-256/SHA-1/MD5/CRC32, secure delete (DoD 5220.22-M), steganography (hide text/files in PNG via LSB).
- **QR generator/reader** for URLs.

### System and security

- **Elevation framework**: per-operation UAC, never full process. App always runs as normal user.
- **WinGet**: structured operations with UAC.
- **WSL**: status, list, update, shutdown, start.
- **ClamAV**: install, update definitions, quick/full/custom scans with live progress, history, real cancellation of elevated scans.
- **Security Center**: Windows Defender status, open ports, startup programs, DNS cache, scheduled tasks, shares, hosts file, BitLocker, SMBv1, process review, active TCP connections with owner process.
- **Windows repair**: SFC, DISM (CheckHealth/ScanHealth/RestoreHealth) with UAC per operation.

### SSH / PGP

- SSH key generation and management.
- PGP keys with Ed25519 or RSA (2048/3072/4096), encrypt/decrypt/sign/verify.

### Local Share (LAN file transfer)

- Direct peer-to-peer transfer over TLS, mDNS discovery, Bluetooth-style 6-digit pairing.
- Integrity (SHA-256 streaming), resume by offset, pause/resume, cancellation, bandwidth limits.
- Text messages between paired peers.
- Temporary web client: token-gated HTTP link with expiry, any browser can download.
- Hardened against MITM: TLS 1.2/1.3 with mutual auth, cert pinning, numeric comparison, anti-replay, pairing rate limiting.

### Web inspector

- URL inspection: homoglyphs, punycode, typosquatting.
- TLS certificate inspection, HTTP security headers, DNS resolution, email validation (MX/SPF/DMARC/DKIM).
- Redirect expansion, tracking-parameter cleaner, URL comparison.

### AI module

- markItDown: detect Python + markItDown, install via pip, convert files (PDF, DOCX, XLSX, PPTX, images, audio, HTML) to Markdown.
- Ollama: detection and local model listing.

### Production UX

- Dark/light/system themes (dark as primary), persisted preference.
- Settings page, favorites, global search (Ctrl+K), keyboard shortcuts, toast notifications + activity center.
- Smart clipboard detection (JSON/JWT/SSH/PEM) with tool suggestions.
- First-run onboarding, deep linking, accessibility (WCAG 2.1 AA), reduced motion, touch targets.
- Auto-update with PGP-signed manifest, SHA-256 verification, UAC install, rotation warning.

### Quality

- Backend: .NET 10, xUnit (hundreds of tests).
- Frontend: React 19, TypeScript, Tailwind CSS 4, Vite.
- Typed message bridge (no arbitrary command execution).
- Per-operation elevation (never full process).
- No secrets in logs; no stack traces in UI.

#### Compatibility note

All protocol changes are additive: a PCSuite 0.10.x receiving transfers or messages from a 1.0.0 processes them exactly as before.
````
